# CORE-AI GUI v20

The GUI has been redesigned as a chat-first interface with:

- compact, independently scrolling left sidebar
- recent conversations in the sidebar
- minimal top bar
- centered chat column
- large rounded composer
- plus menu on the left of the composer
- Function, microphone, Think, and send controls
- Enter-to-send and Shift+Enter newline
- working animation and truthful error cards
- responsive mobile sidebar

No backend authority was moved into the web client.
