# Google Search setup

CORE-AI can always create a real Google search link using `/search <query>` or `/google <query>`.

For real Google-powered results rendered inside the CORE-AI workspace, create a Google Programmable Search Engine and paste its `cx` Search Engine ID into Workspace > More > Google Search > Connect Google Search.

Google documents the Programmable Search Element using a `gcse-search` element and an asynchronous script loaded with the `cx` value.
