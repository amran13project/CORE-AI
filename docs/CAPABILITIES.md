# Capability Matrix

## Implemented foundation

Native C++20 core, local model routing, Ollama adapter, chat, reasoning wrapper, memory, projects, workflows, tool registry, permissions, audit logging, verification primitives, plugin loading foundation, GUI contract, web/map URL adapters, tests.

## Adapter contracts / external backend required

Web search APIs, image generation, vision-capable models, voice/STT/TTS, browser automation, cloud model providers, embeddings/vector search, remote storage.

## Planned advanced systems

Streaming model transport, structured JSON tool calls, RAG indexing, SQLite memory, multimodal sessions, agent evaluation/replay, project graph indexing, sandboxed process execution, signed plugins, browser worker, code workspace, automation scheduler, multi-model routing with cost/latency policy, telemetry, offline model manager.

CORE should become broader than a single-purpose AI website by composing these systems locally, but the project does not claim that roadmap features already exist.
