# CORE AI Full Platform Scope

CORE is intended to become a general personal intelligence platform rather than a single chatbot.

### AI Studio
Chat, reasoning, coding, agent mode, model routing, structured tool calling, multimodal sessions.

### Knowledge
Persistent memory, project memory, library, RAG/vector search, document indexing, citations/evidence.

### Creation
Code workspace, project files, image generation adapter, vision adapter, future media workflows.

### Action
Tool registry, projects, automation, browser adapter, integrations and plugins — all permission gated.

### Reliability
Audit log, verification boundary, deterministic planning, replay/evaluation harness, explicit capability state.

### Extensibility
Native plugin SDK, replaceable GUI, provider adapters and modular source tree.

The goal is broader capability composition than a single web chat surface. It is not a claim that every advanced feature is already implemented in this version.
